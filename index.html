Long-horizon is not memory.

LIBERO and RoboCasa can run for hundreds of steps and still be solvable from the current camera frame. A memory benchmark hides the answer. Watch the yellow cube: it is the whole point.

Three memory regimes

From Gated Memory Policy’s MemMimic. This is the map. Click a tile to keep only that kind of world.

1 · Markovian

Current frame is enough

Tool Hang, LIBERO pick, RoboCasa microwave. History can even hurt a precise policy. Long ≠ memory.

2 · In-trial

The cue appears once

Match Color, RememberColor, Place Back, Shell Game. See a color or a start pose, then it leaves the camera. Hold it until the decision.

3 · Cross-trial

Learn across attempts

Iterative Pushing (MemMimic): friction is secret. Push, miss, remember the miss, push again. Memory is the last trial’s outcome, not the current RGB.

A mobile Franka (PandaOmron) in a full kitchen. Original release: 25 atomic skills — pick-and-place, doors, drawers, knobs, levers, buttons, insertion, navigation — then LLM-authored composite recipes. LIBERO

not memoryOSC_POSE4 suites

GitHub site docs

130 tabletop tasks in four suites: Spatial, Object, Goal, and LIBERO-100 (90 short + 10 long). The research question is lifelong transfer across those suites — not a cue that leaves the camera. Bowls, plates, and cabinets stay in RGB. Same 7-D OSC family as MIKASA; the world is the opposite of RememberColor.

Must remember: the language instruction for this task. Not a hidden object property. env.step([0.]*7) is the published dummy.

Match Color

MemMimicin-trialGMP’s benchmark

GMP GitHub paper site

Pick a cube from one of four colored bins. Bins shuffle. Put it back in the original color. Gated Memory Policy is the method; this is the world.

Must remember: the bin color at pickup. After the shuffle, RGB lies.

Iterative Pushing

MemMimiccross-trial

GMP GitHub

Cube friction is sampled and hidden. Six pushes. Success = last three land in the red box. The policy has to remember overshoots and undershoots.

Must remember: outcomes of prior trials, not a color on the table.

Continuous Place Back

MemMimic · realin-trial

GMP GitHub paper site

Cup on saucer, then back within 5 cm of the start. The start pose leaves the camera the moment the cup lifts. Same memory demand as TakeItBack, on hardware.

Must remember: the cup’s original XY.

The action is usually 7 numbers — except when it isn’t

The trap when you switch simulators is not the length of the vector. It is the frame and whether the numbers are a delta or a pose in the world.
